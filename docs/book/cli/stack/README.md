# kitaru stack

## Usage

```bash
kitaru stack COMMAND
```

## Commands

| Command | Description |
| --- | --- |
| [`create`](create.md) | Create a local, Kubernetes-backed, Vertex AI, SageMaker, or AzureML stack. |
| [`current`](current.md) | Show the currently active stack. |
| [`delete`](delete.md) | Delete a stack by name or ID. |
| [`list`](list.md) | List stacks visible to the current user. |
| [`show`](show.md) | Show translated details for a stack by name or ID. |
| [`use`](use.md) | Use a stack as the active default by name or ID. |
