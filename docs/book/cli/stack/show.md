# kitaru stack show

## Usage

```bash
kitaru stack show NAME-OR-ID [OPTIONS]
```

## Parameters

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `NAME-OR-ID` | `str` | Yes |  | Stack name or ID. |
| `--output`, `-o` | `str` | No | `"text"` | Output format: "text" (default) or "json". |
