# kitaru stack use

## Usage

```bash
kitaru stack use STACK [OPTIONS]
```

## Parameters

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `STACK` | `str` | Yes |  | Stack name or ID to activate. |
| `--output`, `-o` | `str` | No | `"text"` | Output format: "text" (default) or "json". |
