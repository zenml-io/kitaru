# kitaru model

## Usage

```bash
kitaru model COMMAND
```

## Commands

| Command | Description |
| --- | --- |
| [`list`](list.md) | List model aliases available to `kitaru.llm()` in this environment. |
| [`register`](register.md) | Register or update a model alias used by `kitaru.llm()`. |
