# kitaru clean

## Usage

```bash
kitaru clean COMMAND
```

## Commands

| Command | Description |
| --- | --- |
| [`all`](all.md) | Reset all local state: project + global. |
| [`global`](global.md) | Reset all local Kitaru and ZenML state on this machine. |
| [`project`](project.md) | Remove the project-local .kitaru/ directory. |
