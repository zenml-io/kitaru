# kitaru log-store

## Usage

```bash
kitaru log-store COMMAND
```

## Commands

| Command | Description |
| --- | --- |
| [`reset`](reset.md) | Clear the persisted global runtime log-store override. |
| [`set`](set.md) | Set the global runtime log-store backend override. |
| [`show`](show.md) | Show the effective global runtime log-store configuration. |
