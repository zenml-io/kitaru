---

# kitaru secrets delete

## Usage

```bash
kitaru secrets delete NAME-OR-ID [OPTIONS]
```

## Parameters

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `NAME-OR-ID` | `str` | Yes |  | Secret name or ID. |
| `--output`, `-o` | `str` | No | `"text"` | Output format: "text" (default) or "json". |
