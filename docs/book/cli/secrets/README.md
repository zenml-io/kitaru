# kitaru secrets

## Usage

```bash
kitaru secrets COMMAND
```

## Commands

| Command | Description |
| --- | --- |
| [`delete`](delete.md) | Delete a secret by exact name or exact ID. |
| [`list`](list.md) | List all secrets visible to the current user context. |
| [`set`](set.md) | Set a public secret by default, or create it privately with --private. |
| [`show`](show.md) | Show a secret with metadata and optional raw values. |
