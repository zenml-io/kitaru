# kitaru auth api-keys

## Usage

```bash
kitaru auth api-keys COMMAND
```

## Commands

| Command | Description |
| --- | --- |
| [`create`](create.md) | Create a service-account API key and print its one-time value. |
| [`delete`](delete.md) | Delete an API key. |
| [`list`](list.md) | List API-key metadata for a service account. |
| [`rotate`](rotate.md) | Rotate an API key and print its one-time replacement value. |
| [`show`](show.md) | Show API-key metadata without revealing the raw key value. |
| [`update`](update.md) | Update API-key metadata without revealing the raw key value. |
