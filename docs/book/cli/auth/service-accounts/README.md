# kitaru auth service-accounts

## Usage

```bash
kitaru auth service-accounts COMMAND
```

## Commands

| Command | Description |
| --- | --- |
| [`create`](create.md) | Create a service account. |
| [`delete`](delete.md) | Delete a service account. |
| [`list`](list.md) | List service accounts. |
| [`show`](show.md) | Show service-account metadata. |
| [`update`](update.md) | Update service-account metadata. |
