# kitaru auth service-accounts delete

## Usage

```bash
kitaru auth service-accounts delete NAME-OR-ID [OPTIONS]
```

## Parameters

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `NAME-OR-ID` | `str` | Yes |  | Service-account name or ID. |
| `--yes`, `-y` | `bool` | No | `False` | Skip confirmation prompt. |
| `--output`, `-o` | `str` | No | `"text"` | Output format: "text" (default) or "json". |
