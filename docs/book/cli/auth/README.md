# kitaru auth

## Usage

```bash
kitaru auth COMMAND
```

## Commands

| Command | Description |
| --- | --- |
| [`api-keys`](api-keys/README.md) | Manage service-account API keys. |
| [`service-accounts`](service-accounts/README.md) | Manage Kitaru service accounts. |
| [`token`](token.md) | Print a short-lived bearer token for the active Kitaru server. |
