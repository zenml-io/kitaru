# kitaru analytics

## Usage

```bash
kitaru analytics COMMAND
```

## Commands

| Command | Description |
| --- | --- |
| [`opt-in`](opt-in.md) | Enable anonymous usage analytics. |
| [`opt-out`](opt-out.md) | Disable anonymous usage analytics. |
| [`status`](status.md) | Show the current analytics preference. |
