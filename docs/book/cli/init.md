# kitaru init

## Usage

```bash
kitaru init [OPTIONS]
```

## Parameters

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--path` | `str` | No | `None` | Directory to initialize. Defaults to the current working directory. |
| `--output`, `-o` | `str` | No | `"text"` | Output format: "text" (default) or "json". |
