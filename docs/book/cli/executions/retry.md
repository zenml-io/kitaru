# kitaru executions retry

## Usage

```bash
kitaru executions retry EXEC-ID [OPTIONS]
```

## Parameters

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `EXEC-ID` | `str` | Yes |  | Execution ID. |
| `--output`, `-o` | `str` | No | `"text"` | Output format: "text" (default) or "json". |
