---
description: "Resume a paused execution when it did not continue automatically after input."
---

# kitaru executions resume

## Usage

```bash
kitaru executions resume EXEC-ID [OPTIONS]
```

## Parameters

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `EXEC-ID` | `str` | Yes |  | Execution ID. |
| `--output`, `-o` | `str` | No | `"text"` | Output format: "text" (default) or "json". |
