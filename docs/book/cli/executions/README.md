# kitaru executions

## Usage

```bash
kitaru executions COMMAND
```

## Commands

| Command | Description |
| --- | --- |
| [`cancel`](cancel.md) | Cancel a running execution. |
| [`get`](get.md) | Show detailed information for one execution. |
| [`input`](input.md) | Resolve pending wait input for a non-interactive or timed-out execution. |
| [`list`](list.md) | List executions with optional filters. |
| [`logs`](logs.md) | Fetch runtime log entries for an execution. |
| [`replay`](replay.md) | Replay an execution from a checkpoint boundary. |
| [`resume`](resume.md) | Resume a paused execution when it did not continue automatically after input. |
| [`retry`](retry.md) | Retry a failed execution as same-execution recovery. |
