# kitaru flow deployments

## Usage

```bash
kitaru flow deployments COMMAND
```

## Commands

| Command | Description |
| --- | --- |
| [`curl`](curl.md) | Generate a curl command that starts a deployment execution. |
| [`delete`](delete.md) | Delete one deployment version when no exclusive tag protects it. |
| [`list`](list.md) | List deployment versions for one flow. |
| [`logs`](logs.md) | Fetch runtime logs for an execution associated with a deployment. |
| [`show`](show.md) | Show one deployment version. |
