# kitaru flow show

## Usage

```bash
kitaru flow show FLOW [OPTIONS]
```

## Parameters

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `FLOW` | `str` | Yes |  | Deployment-backed flow name. |
| `--output`, `-o` | `str` | No | `"text"` | Output format: "text" (default) or "json". |
