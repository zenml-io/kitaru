# kitaru flow

## Usage

```bash
kitaru flow COMMAND
```

## Commands

| Command | Description |
| --- | --- |
| [`deployments`](deployments/README.md) | Inspect and manage existing deployment versions for a flow. |
| [`list`](list.md) | List flows that have deployment versions. |
| [`show`](show.md) | Show deployment summary for one flow. |
| [`tag`](tag.md) | Attach or move a public tag on one deployment version. |
| [`untag`](untag.md) | Remove a public tag from one deployment version. |
