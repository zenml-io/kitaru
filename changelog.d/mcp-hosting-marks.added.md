- Kitaru's MCP tool list (`kitaru.mcp.registry.TOOL_SPECS`) now tells a host how to run each tool. Each `ToolSpec` carries `run`, the function that does the tool's work with the server state, and `needs_server`, which is `False` for `kitaru_docs_search` and `kitaru_feedback_draft` because they work without a Kitaru server or sign-in.
- Add the `stateless` MCP setting for a server that runs as several copies. With it on, `kitaru_failure_matrix` returns no `snapshot_id`, and `kitaru_failure_matrix_cell` always reads the sessions again. It is off by default, so the local server keeps its current behavior.
