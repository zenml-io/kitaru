The Claude Agent SDK, PydanticAI, OpenAI Agents, LangGraph, Mastra, and Vercel AI SDK adapters and the Langfuse, LangSmith, Logfire, Phoenix, MLflow, Mastra, ElevenLabs, and Braintrust importers fill it when the source reports cache writes.
