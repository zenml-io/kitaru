- `kitaru_connections_manage` now refuses an `env` key that looks like a credential, such as `OPENAI_API_KEY`, `HF_TOKEN` or `DB_PASSWORD`, and asks for it in `secrets`. `env` values are stored unencrypted and readable by anyone who can read the connection, while `secrets` are encrypted and never returned. Settings that only resemble credentials, such as `MAX_TOKENS`, are still accepted.
