- Added `kitaru workspace push --to URL`, which copies agents with their versions, provider connections, settled sessions with their nodes, and insights from the selected server to another Kitaru server. Session, node, and agent ids inside copied insights are rewritten to the destination records, a repeated push copies nothing twice, `--agent` limits the push to named agents, `--copy-secrets` includes connections that hold secret values, and `--dry-run` reports without writing.
