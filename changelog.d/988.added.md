- Added the independently packaged `kitaru-post-import-insights` analyzers. Select `kitaru/post-import-insights` for deterministic analysis, `kitaru/openai-post-import-insights` for OpenAI-backed selection and wording, or both for independent results. A bounded deterministic profiler computes chart candidates and investigation prompts; the OpenAI analyzer requires a model and credentials through a provider connection or eligible worker. Cards carry versioned evidence and coverage metadata; their stored prompts preserve the displayed description, deterministic facts, optional `check_first` caveat, and whether the supplied session IDs cover the full affected population or a retained subset. The plugin fetches sessions through the SDK. The server registers both exact package entrypoints without installing the implementation.
