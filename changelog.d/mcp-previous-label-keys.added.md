- Add the `previous_label_keys` MCP setting (`KITARU_MCP_PREVIOUS_LABEL_KEYS`, a JSON array of strings, each at least 32 characters and kept byte for byte as `KITARU_MCP_LABEL_KEY` held it). On a `stateless` server, after a `label_key` rotation, `kitaru_failure_matrix_cell` still opens the cells of a matrix built with one of those earlier keys. A server that keeps matrices in memory answers cells from that copy instead, which a restart to rotate the key drops first, so the cell asks for the matrix to be built again.
