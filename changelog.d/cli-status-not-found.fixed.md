- `kitaru status`, `kitaru info`, `kitaru doctor`, and `kitaru login` now share one explanation when the selected URL answers HTTP 404: the error names the URL, says it did not answer as a Kitaru server, and hints at `kitaru doctor` or `kitaru login`, instead of `kitaru status` failing with a bare `Error: Not found`. API errors with an empty response body now render a message that names the status code.
