- Added a way to rerun analyzers over the sessions of an existing import. Call `POST /api/v1/imports/{import_id}/analyze` or `client.imports.analyze(...)` with a list of analyzer configs, or run `kitaru import analyze IMPORT_ID --analyzer ANALYZER@VERSION` with the same `--analyzer-params` and `--analyzer-connection` options as `kitaru session import`. Each call creates a new job of kind `analysis` holding one analysis task per analyzer, scoped to the import exactly like the tasks its import job ran, so a failed or misconfigured analyzer can be run again without importing the file into a fresh agent. An import with no completed or failed session is rejected with HTTP 409.
