- Session nodes are identified by `external_id` instead of a numeric position. Parents are referenced by `parent_external_id`, and any other relation by `links`, each naming a target `external_id` and a `kind`. `index`, `parent_index`, `secondary_parent_indexes`, `parent_id`, and `secondary_parent_ids` are gone from requests and responses. Build the node tree from `external_id` and `parent_external_id`. Nodes are listed by start time, then insertion, and a parent may arrive after its children.
- An import whose source yields one session twice now adds the second batch of nodes to the session it created for the first, reported as `skipped`. A node is replaced when its external id already exists and added when it doesn't.
