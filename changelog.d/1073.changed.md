- Session nodes are identified by `external_id` instead of a numeric position. Parents are referenced by `parent_external_id` and `secondary_parent_external_ids`. `index`, `parent_index`, and `secondary_parent_indexes` are gone from requests and responses. Nodes are listed by start time, then insertion, and a parent may arrive after its children.
- Re-importing a session under the same source identity now adds the batch to the session that already exists instead of leaving it untouched. A node is replaced when its external id already exists and added when it doesn't, and a later trace of the same session or thread is appended. The import receipt still reports these sessions as `skipped`.
- Creating a session with a source identity that already exists now returns that session instead of failing, so an import can contribute nodes to a session it did not create.
