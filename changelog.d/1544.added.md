- Added `kitaru workspace push --to URL`, which copies agents with their versions, provider connections, settled sessions with their nodes, and insights from the selected server to another Kitaru server. Session, node, and agent ids inside copied insights are rewritten to the destination records, a repeated push copies nothing twice, `--agent` limits the push to named agents, and `--dry-run` reports without writing. The push refuses a destination that reports the source's server id and needs no login for a destination without authentication. Connections arrive without their secret values, which a server never returns, and the result names the secret keys to set on the destination; such a connection becomes the provider's default only through the printed command, once its secrets are set. A partial failure prints its report in text mode and is retryable only when every failure is.
