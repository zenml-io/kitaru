- The session viewer page now sends each tool input argument besides `request`, such as a host's workspace, with every read and save about the session it opened, and keeps the session on screen paired with its workspace until another session replaces it. A save that finishes after another session opened no longer shows among that session's notes, and an open note box or floating "+ Note" button goes away when another session opens; rendering the same session again keeps them. A verdict saved while the same session renders again stays shown, and an unsaved answer stays with its investigation when the same session opens in another one.
