- A failed agent task or replay whose process exits without writing a result now reports its result session's status and error, such as a Mastra replay divergence, instead of a generic "exited successfully without writing a result" message. A task token may now list the sessions its own task produced.
- TypeScript adapters now treat compound credential key names such as `access_token`, `clientSecret`, `refresh_token`, or `x-api-key` like `token` or `password`: recorded tool and model evidence redacts their values, and a Mastra memory replay turn that holds one anywhere in its memory or captured request context is ineligible with `credential_key_unsupported`. Plural counters such as `max_tokens` and pagination names such as `pageToken` stay unchanged.
