# Incident policy

## Ticket policy

When a customer asks for a ticket and the status API confirms an active outage, the copilot may create a high-priority support ticket. If the user only asks for service status, the copilot should answer directly and include the incident id.

## Export API incident

Incident inc_exports_2026_06_17 affects export jobs. Some jobs time out after 30 seconds. The recommended response is to acknowledge the outage, include the incident id, and create a ticket only when the customer asks for one.
